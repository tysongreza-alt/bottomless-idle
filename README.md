# BOTTOMLESS: Idle Excavation

An independent, mobile-first idle drilling game for personal and family use. No ads or subscriptions.

## Play
Open the GitHub Pages link in a phone browser. On iPhone, tap Share > Add to Home Screen. On Android, use Chrome's Install app or Add to Home screen option.

## How to play
Your drill mines automatically. Buy POWER, SPEED, and VALUE upgrades with coins, use POWER SLAM when available, discover biomes, and optionally REBUILD when you reach depth 120 to earn permanent cores.

## Saving and offline use
Progress is saved locally in the browser on each device. You can export and import save backups from the in-game menu. Clearing browser data, using private browsing, reinstalling the app or changing phones may remove local saves. There is no shared cloud save or leaderboard in this version. The app has a service worker for offline access after a successful first load.

## Files
- index.html: full self-contained game
- manifest.webmanifest: mobile install manifest
- sw.js: offline cache
- icon-192.png and icon-512.png: app icons
